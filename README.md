## Overview

Crypto portfolio tracker showing top 20 assets by market cap with live prices, 24h changes, volume, supply, and dominance bars.

Built with **Next.js 16** (App Router, TypeScript), **shadcn/ui**, **Tailwind CSS 4**, and **Framer Motion**.

## Features

| Area | What it does |
| --- | --- |
| **Market Data** | Top 20 crypto assets with real-time prices from CoinCap API. |
| **Summary Card** | Total market cap, average 24h change, best performer. |
| **Price Changes** | Color-coded badges with trend icons for 24h changes. |
| **Dominance Bars** | Visual market cap dominance bars per asset. |
| **Responsive** | Progressive column reveal on mobile/tablet/desktop. |
| **Error Handling** | API error detection with retry. |

## Tech Stack

| Layer | Technology |
| --- | --- |
| **Framework** | Next.js 16 (App Router, TypeScript) |
| **UI Components** | shadcn/ui (Radix + Tailwind) |
| **Styling** | Tailwind CSS 4 with CSS variables |
| **Animations** | Framer Motion |
| **Icons** | Lucide React |
| **API** | CoinCap API v2 (free) |

## Getting Started

```bash
git clone https://github.com/RivaldiDev/crypto-portfolio.git
cd crypto-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
